# Prototype limits

- Synthetic administrative offices, special weekend shifts and exactly 12 synthetic recipients. No real USDA identity or official operating authority.
- Only flood warnings, high-wind warnings and modeled AQ triggers are assessed automatically. Unsupported hazards require human review. Delay/dismissal require manager-selected timing and evidence/assumption.
- Alert expiry is not proof of safety; closure does not direct evacuation. Essential personnel require supervisor direction. No invented leave entitlement, travel safety instruction or AQ wildfire inference.
- Freshness budgets are engineering assumptions; confidence is evidence completeness, not decision probability.
- NWS point confirms location. Explorer requires a valid polygon and point-confirmed alert plus NWS timezone; no polygon/zone fallback is fabricated.
- Air-quality coverage is modeled, not measured at a building. Null/stale/incomplete windows stay incomplete. AQ values are shown unrounded; >=151 is the prototype cutoff.
- Missing AI credentials or failed tools produce explicit unavailable/degraded output, preserving the deterministic assessment.
- Notification packages are draft/queued_demo only. No real send integration or enterprise identity. HTTP Basic only through loopback, SSH or approved HTTPS.
- Immutable SQLite tables/hash checks are prototype audit protection, not compliance certification.
- SIMULATION is reserved and refused at manager-decision boundary; no what-if UI implemented before verified P0.
- Real Strands tool use, Linux/container deployment, remote persistence and full Akamai workflow were verified on 2026-10-10; see PROJECT_STATE.md for exact evidence. Public judging access and organizer requirements remain pending.
