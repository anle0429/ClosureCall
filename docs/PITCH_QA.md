# Pitch questions

- **What does the agent add beyond rules?** One Strands agent reads five frozen tools and selects scoped references/review focus. Rules control posture/routing; the manager approves. The agent has no approval, sending, shell or cloud tool.
- **Wrong location or time?** Point/location, supplied polygon, time overlap and snapshot-reference checks have regression coverage. Null-geometry coverage relies on NWS point filtering; internally consistent but wrong metadata can evade checks. Offline fixtures are not a claimed live incident.
- **Zero alerts versus missing data?** An available empty feed differs from failed/unverified retrieval. Neither verifies local safety, power, water or security.
- **Replace OnSolve/the emergency team?** No connector/import compatibility or staffed monitoring service. This supports evidence review, human decision records and draft preparation.
- **Essential reporting?** Supervisors and established local procedures decide it. Closure does not mean evacuation or automatically require essential personnel to report.
- **Deferred?** Manual supervisor review before shift, or immediately if ongoing. Onsite reassignment requires a new evaluation/decision; no automatic follow-up/send job.
- **Messages delivered?** No. Channel labels describe drafts; excluded staff have explanations. No delivery receipts exist.
- **Indoor AQ?** No. Open-Meteo/CAMS is modeled grid data; valid time, retrieval time and returned grid are disclosed.
- **Model fails?** Show unavailable/degraded, retain deterministic evidence and require review where appropriate. Never substitute old AI output. Post-event workshop availability is not newly verified.
- **USDA policy?** No. Prototype mappings/confidence are assumptions, not approved federal policy or safety probability. Reported USDA feedback is not endorsement.
- **Frozen history?** Evidence, rules, roster, AI trace/output, actor/time/reason and drafts. Replay/export do not fetch sources/model. Candidate memo-v2 changes presentation only; production retains memo-v1.
- **Tamper-proof?** No. Hashes/immutable tables detect ordinary changes; privileged host access is outside that guarantee.
- **Akamai?** Private FastAPI app and persistent SQLite run on the existing Linode. Dated real Strands calls are retained; local QA calls no provider/model.
- **Public/deployed/submitted?** GitHub source is public under the owner's October 13 authorization. The deployed app remains private and the portfolio candidate is undeployed. LinkedIn copy is a draft; submission remains ON_HOLD. No project license selected.
