# ClosureCall — submission material

ClosureCall helps facility managers turn live weather and operational evidence into a reviewed operating decision, targeted employee instructions, and a reconstructable record.

Targets USDA Closure Call, AWS Strands and Akamai. It runs on the user's existing Akamai Linode, using NWS live alerts, Open-Meteo/CAMS modeled air quality, explicit prototype rules and one real Strands agent. The agent can read frozen evidence/policy/impact tools; manager decisions and notifications remain outside its authority. Model-selected references are validated and factual text comes from frozen records.
